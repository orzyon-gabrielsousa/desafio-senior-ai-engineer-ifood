# Fichas dos pratos — o que cada um pede da cozinha

> Os requisitos são o que um prato **precisa** para sair da cozinha. Os custos são **de exemplo** (custo típico dos ingredientes por porção), criados para a demonstração do desafio: troque pelo custo real da sua operação.

Como ler: **Precisa de** lista o que não dá para fazer sem (separado por vírgula; `A ou B` quer dizer que um dos dois basta). **Habilidades** são o que a Dona Maria precisa saber fazer. **Custo típico** é o que os ingredientes custam por porção. Os nomes são os da tela **Minha cozinha** (veja o README da pasta).
